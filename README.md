## Overview

**Casa Silente** (*"Silent House"*) is a complete first-person horror game inspired by the tension of *Granny* and the lights-out atmosphere of *Phasmophobia*. You wake up in an abandoned school classroom inside a huge, dark house. Something is hunting you.

The entire game — a custom 3D engine, physically based rendering, procedural textures, 3D models and a synthesized horror soundtrack — is written in **vanilla HTML, CSS and JavaScript**. There are **no frameworks, no libraries, no external assets, no installation and no server**. Download, double-click `index.html`, play.

## Key Features

- **Custom WebGL2 Engine** — PBR shading (GGX specular, bump mapping, procedural reflections), baked colored lightmaps, shadow-mapped flashlight, HDR pipeline with MSAA, bloom, ACES tone mapping, film grain, vignette and chromatic aberration.
- **Dynamic Lighting** — Every room has its own switchable, flickering lights. The monster turns them off. Your flashlight casts real shadows, drains battery and flickers when low.
- **Intelligent Monster AI** — Patrols, hears noises (running, doors, flashlight clicks), investigates, hunts you down with path-finding, searches when it loses you, and periodically triggers *hunt phases*.
- **Procedurally Generated House** — Dozens of rooms (classroom, kitchen, bedroom, library, office, cell…) generated per seed. Keys, weapon, ammo, batteries and notes are hidden in **different random places every run**.
- **Five-Day Structure** — Get caught and you wake up in a locked **cell** with lockers. Find the hidden cell key to get out — but another day has passed. Caught on **Day 5** and it's game over: you start again from scratch.
- **Two Ways to Win** — **Escape** through the front door with the hidden key, or find the hidden pistol and **kill** the monster.
- **Hide & Survive** — Hide in wardrobes, crouch to stay silent, manage stamina and battery.
- **Procedural Horror Music & Audio** — Dissonant evolving pads, detuned music-box melodies, reversed swells and heartbeat, all synthesized in real time with the Web Audio API. Music intensity follows your fear level and chase state.
- **Zero Assets** — Every texture, model and sound is generated by code at load time. The whole game is under 80 KB zipped.
- **Full Options Menu** — Graphics, audio mixing, difficulty, FOV, resolution scale and more, saved automatically.

## How to Play

1. You start in the **classroom**. Read the **blackboard** (`E`) for your mission.
2. Search lockers, cabinets, wardrobes, fridges and drawers for **notes**, **batteries**, the **front-door key**, a **hidden pistol** and **ammo**. Notes hint at where to look.
3. Stay quiet. Running, firing and slamming doors attract the monster.
4. If it catches you, you wake up in the **cell**. Search the lockers for the cell key, escape, and keep going — but **a day is lost**.
5. **You have 5 days.** Get caught on day 5 and you lose everything.
6. **Win** by unlocking the front door and escaping, or by shooting the monster dead.

## Quick Start

### Option 1 — Just play (recommended)

1. Download the repository as a ZIP (**Code → Download ZIP**) and extract it.
2. **Double-click `index.html`.**

That's it. No Node.js, no build step, no internet connection.

### Option 2 — Local server (optional)

```bash
git clone https://github.com/nowii-core/Casa-Silente.git
cd Casa-Silente
npx serve .        # or: python -m http.server 8000
```

Then open the printed address in your browser.

### Requirements

- A modern desktop browser with **WebGL2**: Chrome, Edge, Firefox or Safari (latest versions).
- A GPU with hardware acceleration enabled for the best experience.
- If the game stutters: **Options → Graphics → Quality → Low / Medium** or lower the **Resolution**.

## Options & Settings

All settings are available from the main menu and the pause menu, and are saved in your browser.

| Tab | Settings |
|---|---|
| **Graphics** | Quality preset (Low / Medium / High / Ultra), resolution scale, field of view, brightness, film grain, bloom, FPS counter |
| **Audio** | Master volume, music volume, effects & ambience volume |
| **Game** | Monster difficulty, mouse sensitivity, invert Y axis, camera bob, on-screen hints |

### Difficulty

## Technology

| Area | Details |
|---|---|
| **Language** | JavaScript (ES6+), HTML5, CSS3 — no frameworks, no bundlers |
| **Rendering** | Custom WebGL2 engine: uber PBR shader, baked lightmaps, PCF shadow mapping, HDR RGBA16F, MSAA 4×, 5-level bloom, ACES grading |
| **Content** | Fully procedural: textures (value-noise / fBm), geometry (primitives & lathes), house layout, item placement |
| **AI** | Grid flow-field (BFS) pathfinding, state machine (patrol / investigate / chase / search / grab), noise & line-of-sight perception |
| **Audio** | Web Audio API synthesis — oscillators, filtered noise, delay feedback, adaptive music layers |
| **Persistence** | `localStorage` for settings |

## Project Architecture

```
Casa-Silente/
├── index.html          # Entry point: canvas, HUD and all menus
├── css/
│   └── style.css       # Horror UI theme: HUD, menus, custom dropdowns
├── js/
│   ├── util.js         # Math helpers, seeded RNG, noise
│   ├── audio.js        # Procedural SFX, ambience & adaptive horror music
│   ├── gl.js           # WebGL2 wrapper, matrices, geometry primitives, scene nodes
│   ├── textures.js     # Procedural texture generation
│   ├── mats.js         # PBR material definitions
│   ├── models.js       # Furniture, props, items, flashlight, pistol, monster
│   ├── house.js        # Procedural house & room layout, item placement
│   ├── world.js        # Collision, lightmap baking, meshes, doors
│   ├── fx.js           # Particles, decals, flashlight beam & dust
│   ├── render.js       # Renderer: shaders, shadows, HDR, bloom, post-processing
│   ├── game.js         # Game logic: player, monster AI, days, win/lose
│   └── ui.js           # Menus, options, HUD, input, main loop
├── LICENSE
└── README.md
```

## Troubleshooting

| Problem | Solution |
|---|---|
| Black screen / "WebGL2 not supported" | Update your browser and enable hardware acceleration |
| Low FPS | Lower quality preset and/or resolution scale in **Options → Graphics** |
| No sound | Click once inside the page (browsers require a user gesture), then check **Options → Audio** |
| Mouse not captured | Click the game window; press `Esc` to release |
